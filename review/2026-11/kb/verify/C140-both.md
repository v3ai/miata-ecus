# C140 verdict: partly
Checked: GitHub issue 4310 (via API) and forum p=47554 (page fetch). Issue 4310 confirms the hellen88bmw / 3-phase VFD / USB descriptor failure / red FATAL report. In the forum thread the isolator report is from Dron_Gus (Proteus, cranking, charger plus ECU both on laptop). The thread does not mention a VFD, and it does not say the reporter's problem was solved. "A second forum user cured" is loosely stated. Maintainer non-reproduction not checked (p=48645 not fetched).
Not a defect of this design: it is a field report about other ECUs. The repo (INSTALL.md, README) has no USB isolator or ground-loop advice, and review brief s6 does not list it. So it is a documentation/support suggestion at most, not a board error. No evidence this board's USB-C (ESD/filter) is deficient. Applies equally to ordered and current boards (generic, not rework-worthy).
Corrected statement: anecdotal upstream reports of USB dropouts with ground-loop or EMI (VFD; charger plus laptop while cranking), cured by an ADuM3160 isolator in one confirmed case. Not tied to this hardware. Fix: one line in INSTALL troubleshooting (battery laptop or isolator, short cable). Severity low.
