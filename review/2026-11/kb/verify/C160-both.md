# C160 verdict: partly (facts true, "cheapest observed" is a non-comparable benchmark, no action)
Checked: kb/research/files/R06/blitzbox_v0.1.9_bom_2025-01-08.csv has SS54 (C2827918), SMBJ22A (C135058), LM2940G-50-AA3-R (C71094). Live tools/lcsc.py today: SS54A $0.045, SMBJ22A-13-F $0.144 (stock 318), LM2940G-50 $0.197, rated -40..+85 C, 1 A. Sum $0.386, so "about $0.4" is right.
Project's own chain (evidence/cur_db/sch_bom_grouped.csv, kb/parts_manifest.md): SMCJ30A $0.30, SS34 $0.035, LMR14020 buck $0.69 (plus inductor), about $1.0. Cheaper only because an LDO is used instead of a buck; at 14.4 V in, an LDO dissipates (14.4-5)*I (about 0.3 W per 30 mA, about 2.8 W at 300 mA), which is not workable for an STM32 plus wideband load in SOT-223 with an 85 C part. The claim itself says thermal margin is not checked. Blitzbox is a lower-load ATmega design; "cheapest" is a survey of 13 hobby designs, not an equivalent function.
(a) Not documented, but only a benchmark, so not news. (b) Not ordered-board relevant (ordered=false; nothing to rework). (c) No saving is recommended or achievable: swapping to LDO would be a thermal risk; the saving would be at most about $0.6 per board and would also drop the rail's load capability.
Corrected statement: Blitzbox uses SS54A + SMBJ22A + LM2940G-50 totalling about $0.39 at JLC today; this is cheaper than this project's SMCJ30A+SS34+LMR14020 (~$1.0) only because it uses an 85 C LDO unsuited to this project's load. Informational, not a recommendation.
