# C003 consequence check: verdict PARTLY (severity medium, not high)

Checked:
- Ordered mb8993/mb9495/mb9900: IN_SW2 (A/C, 1Q or 1P) -> R21 4.7k to VBAT_IN, IN_SW3 (clutch, 1V) -> R22. R20-R22 are 0603 and not fitted by default (pcb_nets.txt, pcb_footprints.csv). VERIFICATION.md M4 already says "not fitted by default, fit per car", but never says A/C and clutch are ground-switching or what firmware polarity is needed.
- Daughterboard (ord_db): IN_SW2/SW3 go through 22k series, 10k to GND, 10n, 1N4148WS (R67/R68, R69/R70). Unfitted pull-up: open and switch-to-ground both give about 0 V.
- Firmware: repo/firmware/board/miata_board.cpp:112-113 sets only acSwitch and clutchDownPin, no pin modes. rusEFI default acSwitchMode = 0 (active high, no inversion). Debounce inverts only for PI_PULLUP (debounce.cpp:112). engine_configuration.cpp:223 defaults clutchDownPinMode = PI_PULLUP, so the clutch is ALREADY active-low by default. Hellen NB2 sets acSwitchMode = PI_PULLUP (hellenMiataNB2/board_configuration.cpp:89).
- Car: R16 (1990 manual): 1Q A/C switch below 2.5 V = on; 1V neutral/clutch 0 V in, 12 V in gear. These are ground-switched signals read against the stock ECU's internal pull-up. 1P polarity (9900) is still unknown, as the cluster says.

Corrected statement: A/C request is never seen on the ordered boards (acSwitchMode unset, no pull-up), so the ECU never commands the compressor: loss of A/C, not damage. The clutch claim is wrong in detail: with the stock clutchDownPinMode = PI_PULLUP, an unfitted R22 leaves the node at about 0.66 V (internal ~40k pull-up against 10k), which reads low = inverted = clutch permanently "down"; once R22 is fitted the default polarity is correct and no firmware change is needed. Fitting R21 without setting acSwitchMode = PI_PULLUP makes A/C permanently requested (switch open = high). Fitted pull-up: open = 3.27 V at 12 V (divider 12*32/36.7*10/32), 0 V when grounded, 44 mW at 14.4 V (already in VERIFICATION M4).
Severity: medium (feature missing on cars with A/C; clutch only matters if launch/clutch features are enabled). Affects the ORDERED boards, rework is two 0603 resistors by hand.
Fix: hand-fit R21 (and R22 if clutch features used) on each ordered 1989-95 board; set acSwitchMode = PI_PULLUP in the Miata preset (one line; clutch needs none); document in INSTALL. For 1996-2005 confirm 1P polarity on a car before fitting. Cheaper alternative: configure MCU internal pull-up? Not workable because the 22k/10k divider overpowers it (about 0.66 V).
Already documented: partly (resistors not fitted is; polarity requirement is not).
