# C010 consequence check
Verdict: partly. Severity should be low/info for this product.
Checked:
- Thread 107805 (page fetch, today): post #1 says a DiyAutoTune engineer blamed a "ground voltage offset between the alternator and the battery negative", suggested a strap; author says the strap "helped but did not fully solve" it. Second-hand, one owner. The same post blames TunerStudio MegaSquirt "Battery Voltage Correction (ms/v)" (0.2 ms/V above 13.2 V) for lean stalls: MegaSquirt tune setting, not this board.
- Thread 103610: the vendor said the ECU's regulator "was set to always output the maximum voltage"; the fix was a repair at DiyAutoTune (component U1 replaced, 13.5-13.7 V after). This points to a hardware fault in MSPNP2's own onboard regulator, not a ground offset. The two cited threads therefore disagree on cause, and neither is about this design.
- Repo: alternator control ships OFF (README.md:66,100; INSTALL.md:253; VERIFICATION.md M5 line 221 and open item line 1108, with first-run advice "if battery goes past about 15 V switch it off and invert"). So already documented. On 1999-2000 the wire (1O/3M) is a logic PWM input to the alternator's own regulator, so the stock regulator still limits voltage unless the ECU drives it.
Consequence: with the default (off) the ECU does not touch charging; any ground offset would be the same as with the stock ECU. Risk only arises after the owner enables control; the likely failure there is wrong polarity/pull-up (M5), not ground offset. The ordered 99-00 board (rev 0.7) is the same circuit; nothing to rework, as the behaviour is firmware/config.
Corrected statement: Two MSPNP2 owner reports of overcharge exist; one vendor repaired a faulty regulator part, one second-hand anecdote cites ground offset with partial relief from a strap. Not evidence of a defect in this design; M5 already covers the real open item.
Fix: nothing required. Cheap optional: one line in INSTALL "if charging voltage reads high, check alternator body ground strap" (costs nothing); firmware over-voltage cutoff is only useful if the polarity is known (M5), so keep it as a post-first-run item. Verify battery-voltage injector correction table in the base tune is sane (not checked here).
