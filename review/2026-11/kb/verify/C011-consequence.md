# C011 consequence check
Verdict: PARTLY.
- Already documented: review brief s6 ("1996-2005 board outline/mounting holes are placeholders"), repo README.md:92,175-177,253, INSTALL.md:160 (check fit before ordering). Not news.
- True: repo uses NA notched outline + 4 holes (mb_na6.py:16-57), copied from the rusEFI NA6 board; Hellen NA8-96/NB1/NB2 boards are 154 x 159, R7, six holes (R17 notes s6: 154.2x159.2, holes pitch 144 x 148.8).
- Overstated: "real 1996-2005 outline data exists". R17 notes s6 itself says the NA6_94 and NA8_96 boards have identical Edge.Cuts: a Hellen template, not measured stock-case geometry. NB1 donor case is a 2000 Camry case (B11.02), so its holes prove nothing about the Miata NB case; NB2 README only says M4x10 screws. No source gives any 96-05 stock case dimension. So the "fix" holes are equally unverified; fit of the Hellen NA8-96 board in the stock 96-97 case is only inferred ("good to drive" on wiki).
- Consequence: ordered 96-05 motherboards (rev 0.7) may not mount or fit the stock case; this is a fit risk, not electrical. Daughterboard/electronics unaffected; boards can still be bench-powered loose. Not a safety issue; severity medium (high only for the sale of 96-05 units; 89-95 unaffected).
- Fix: do not change outline from Hellen data alone. Measure/photograph an actual 96-97 / 99-05 case (or ask a rusEFI NA8-96 owner for the hole drawing), then adopt. Cheaper: sell 96-05 as "bench/unmounted, provisional" and mount with standoffs/tape until verified. Rework of ordered boards impossible except drilling new holes by hand (possible if the board outline fits).
